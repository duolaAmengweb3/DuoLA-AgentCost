What happens on every request

请求经过本机，账留在本机。

AgentCost 不替你做任务，也不再包一层 AI。它只做确定性控制：安全时减少无效上下文，不确定时原样透传。

What you get

不是再做一个 Agent，
而是给它加上边界。

当任务变长、工具变多、错误开始重复时，真正浪费的是上下文、重试和无人看管的预算。AgentCost 把这些资源变成可以控制、可以复盘的运行数据。

01 / CONTEXT

只处理能证明安全的冗余

清理 ANSI、重复长日志、等价 JSON 和同一请求内的重复结果。代码、错误、工具调用和不确定内容默认原样保留。

02 / CONTROL

预算到了就停，不让任务失控

按请求、会话、项目和 Agent 设置 Token、费用、并发和重复错误边界；触发时明确告诉你为什么被阻断。

03 / PROOF

知道省了什么，也知道没省什么

本地账本记录原始输入、实际发送、Provider usage、成本、延迟、规则和回退尝试，不拿估算冒充真实账单。

A normal user journey

安装一次，继续用原来的 Agent。

免费本地核心不要求 DuoLA 账户。你登录的仍然是 Codex、Claude Code、Cursor 或自己的 Provider。

01 / INSTALL

下载安装

安装一个本地二进制，不安装 Node、Python，也不修改项目代码。

02 / DETECT

自动检测

首次设置自动识别本机 Agent 和协议，生成最小配置，不要求手写 TOML。

03 / CONNECT

接入本机网关

AgentCost 把请求地址临时指向 127.0.0.1，原有配置可恢复。

04 / WORK

照常开发

你继续用原来的命令。请求自动经过本地规则、预算和账本。

05 / REVIEW

查看与退出

打开本机 Dashboard 看结果；需要时一键暂停优化或恢复原始路径。

Trust boundary

数据留在你的环境里。

AgentCost 不是云端代理。你的代码、Prompt、Completion 和 Provider Key 不会因为使用本地控制层而上传给 DuoLA。

默认不需要 DuoLA 账户

免费本地核心可以直接使用。DuoLA 当前不读取你的 Agent OAuth，也不要求绑定账号。

凭证留在 Agent / 本机

已有 Agent 登录态继续由 Agent 使用；独立 Provider 的 Key 只从本机环境变量读取，不写入 AgentCost 配置。

随时恢复原路径

暂停优化、bypass 或退出托管模式后，请求恢复原样转发，Codex 配置会按快照恢复。
