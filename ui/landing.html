The useful layer between

Agent 变快了，

真正昂贵的不是某一次回答，而是任务变长后反复携带的上下文、重复工具输出和无人看管的重试。AgentCost 把这段不可见消耗变成一层确定性的本机控制。

01 / CONTEXT

只处理能证明安全的冗余

清理 ANSI、重复长日志、等价 JSON 和同一请求内的重复结果。代码、错误和不确定内容默认原样保留。

NO SUMMARY
NO GUESS

A normal user journey

安装一次，
继续用原来的 Agent。

免费本地核心不要求 DuoLA 账户。你登录的仍然是 Codex、Claude Code、Cursor 或自己的 Provider，AgentCost 只在中间做可解释的运行控制。

01 / INSTALL

下载安装

固定版本二进制，带 SHA-256 校验。不安装 Node，不改项目代码。

02 / DETECT

自动识别

首次设置识别本机 Agent 和协议，生成最小配置，不要求手写 TOML。

03 / RUN

照常开发

请求经过 127.0.0.1 网关，预算、规则和账本在本机执行。

04 / REVIEW

看清与退出

打开本机 Dashboard 看结果；随时暂停优化或恢复原始路径。
